🔀 Decision Routes from Human Review

✅ Approve

Accept the analysis as-is. Pipeline continues to Alternative Sourcing to find replacement suppliers for HIGH-risk ones.

→ alternatives → END

✏️ Approve with Edits

Modify the executive summary or change supplier action levels (HIGH/MEDIUM/LOW), then proceed to alternatives.

→ alternatives → END

🔄 Send Feedback & Re-analyse

Write what's wrong (e.g., "Japan is only a buyer"). The AI re-reads the article with this feedback injected into the prompt. Up to 3 rounds.

→ monitoring (full re-run with feedback)

⚙️ Edit Extraction Directly

Fix countries/industries/companies by hand. Skips the LLM entirely — only re-runs KG query, risk, visualization, and summary.

→ kg_query (skips LLM, much faster)

🛑 Discard Analysis

Hard stop. The analysis is thrown away. Use when the article is irrelevant or fundamentally misunderstood.

→ END
